# Pull Requests

Na extensão, crie um container com o nome Gitea Classic Toolkit e uma visualização de árvore com o título Pull Requests. A árvore começa com dois itens, Aberto e Fechado. Ao expandir, eles listam os PRs abertos e fechados respectivamente. Limite aos 20 itens mais recentes. No header da view, adicione um botão de atualizar, que recarrega a árvore. Adicione também um botão de incluir para a criação de um novo pull request. Esse comando exibe e foca em um novo container, para a criação do PR. Esse novo container deve te uma webview exibindo o nome da brach base, o nome da branch atual que será mergeada, um caixa para o título e uma caixa para descrição, além dos botões cancelar e criar. Ao cancelar ou criar, ou seja, quando o usuário não estiver mais incluindo um PR, esse container não deve ser exibido. Ainda dentro do container, exibir uma view listando os arquivos que estão sendo alterados nesse PR.
