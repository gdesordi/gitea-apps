# Questionário de Refinamento — Detalhes do PR

## Como responder

Responda abaixo de cada pergunta, mantendo a numeração. Respostas curtas são suficientes. Quando a sugestão estiver adequada, responda `manter sugestão`. Itens marcados como **Essencial** afetam diretamente a implementação.

### 1. Conteúdo dos detalhes

#### 1.1 Informações dos commits

**Essencial** — Quais informações devem aparecer em cada commit listado dentro do PR?

Sugestão: exibir a mensagem do commit, autor e data; clicar no commit não executa nenhuma ação.
