# API do Gitea 1.14.7

O contrato escolhido para referência local é o Swagger 2.0 oficial gerado pelo projeto Gitea na tag `v1.14.7`, em `public/swagger.v1.json`.

- Fonte: https://github.com/go-gitea/gitea/blob/v1.14.7/public/swagger.v1.json
- Download bruto: https://raw.githubusercontent.com/go-gitea/gitea/v1.14.7/public/swagger.v1.json
- Destino planejado: `gitea-1.14.7.swagger.json`

O ambiente de execução não conseguiu resolver `raw.githubusercontent.com` (falha DNS), e a ferramenta de navegação não possui o conteúdo bruto dessa versão em cache. O arquivo JSON ainda precisa ser baixado quando houver acesso de rede. Não usar especificações de versões mais recentes como substitutas, pois este projeto tem como alvo exclusivo a versão 1.14.7.
